# win_sizer

macOS 選單列小工具：拖動任一視窗的標題列，畫面上方會彈出版型圖示，拖進去放開，視窗就變成該版型的大小/位置。

## 下載

到 [Releases](../../releases) 頁面下載最新版的 `win_sizer.app.zip`，解壓縮後把 `win_sizer.app` 拖進「應用程式」資料夾即可。

## 第一次打開

這個 app 沒有 Apple 官方公證，第一次打開 macOS 會跳出警告：

1. 雙擊打開，看到「Apple 無法驗證」的警告，點 **完成**（不要點丟到垃圾桶）
2. 打開「系統設定 > 隱私權與安全性」，往下捲，找到 win_sizer 被封鎖的提示，點 **強制打開** / **仍要打開**
3. 再雙擊打開一次，這次會有「打開」按鈕，點下去即可

## 授權

需要「輔助使用」權限（用來讀取/調整其他視窗的位置與大小）。第一次啟動時 macOS 會跳出請求，前往「系統設定 > 隱私權與安全性 > 輔助使用」開啟即可。

## 版型

- **Left more**：佔螢幕左側 2/3 寬、全高
- **Right more**：佔螢幕右側 2/3 寬、全高
- **Centre**：置中，2/3 寬 x 2/3 高
- **Full Screen**：整個可視區域（扣除選單列與 Dock）
